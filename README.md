# K-ECO SIM
### 한국환경공단 환경 시뮬레이션 종합 플랫폼

탄소중립·자원순환·대기질·신재생에너지·무공해차·물환경 **6대 영역**을
3D 그래픽과 실제 공학 모델로 계산하는 웹 기반 시뮬레이션 도구입니다.

---

## 실행 방법

### 방법 1 — 단일 파일 (가장 간단, 제출·배포용 권장)
```
K-ECO-SIM-단일파일.html
```
이 파일 **하나만 더블클릭**하면 됩니다. USB·이메일로 전달해도 그대로 동작합니다.

### 방법 2 — 개발용 폴더 구조
```
index.html
```
`index.html`을 더블클릭합니다. `assets/` 폴더가 같은 위치에 있어야 합니다.

> ⚠️ 외부 라이브러리를 CDN에서 불러오므로 **인터넷 연결이 필요**합니다.

### 단일 파일 다시 빌드하기
`assets/` 안의 코드를 수정한 뒤 아래를 실행하면 단일 파일이 갱신됩니다.

```bash
node build-standalone.js
```

## 6대 시뮬레이션 모듈과 산정 근거

| # | 모듈 | 적용 모델 · 산식 |
|---|------|------------------|
| ① | **탄소중립 인벤토리** | 2006 IPCC 가이드라인 Tier 1<br>`배출량 = 활동자료 × 배출계수`<br>전력 0.4594 kgCO₂eq/kWh, LNG 2.176 kgCO₂eq/m³ 등 국가 배출계수 |
| ② | **자원순환 물질흐름** | 물질흐름분석(MFA)<br>`재활용량 = 발생량 × 분리배출률 × 선별효율 × 성상별 회수계수`<br>매립 CH₄ 간이계수 0.40 tCO₂eq/t |
| ③ | **대기오염 확산** | Gaussian Plume Model<br>`C = Q/(π·u·σy·σz) · exp(−He²/2σz²)`<br>Pasquill-Gifford(Briggs) 확산계수 · Holland 연기상승식 |
| ④ | **신재생에너지** | 태양광 PVWatts `E = P × H × 365 × PR`<br>풍력 Betz `P = ½ρAv³Cp` (ρ=1.225)<br>이용률 NREL 경험식 `CF = 0.087V − P/D²` |
| ⑤ | **무공해차 인프라** | `전력수요 = 대수 × 주행거리 ÷ 전비 ÷ 충전효율(0.90)`<br>수요가중 K-Means 군집 입지 최적화 |
| ⑥ | **하수처리 공정** | A²O 단위공정별 제거율 모델<br>온도보정 θ=1.047 · `Yobs = Y/(1+kd·SRT)`<br>공공하수처리시설 방류수 수질기준(Ⅲ지역) |

## 사용법

1. **모듈 선택** — 상단 탭에서 6개 시뮬레이션 중 하나를 고릅니다.
2. **조건 입력** — 왼쪽 패널의 슬라이더를 움직이면 결과가 **실시간**으로 재계산됩니다.
3. **3D 확인** — 3D 화면은 드래그로 회전, 마우스 휠로 확대·축소합니다.
4. **보고서** — 마지막 「보고서」 탭에서 전체 결과를 **PDF·Excel**로 내려받습니다.

> 💡 키보드 **1~8** 키로 탭을 빠르게 이동할 수 있습니다.
> 💡 우측 상단 🌙 버튼으로 다크/라이트 테마를 전환합니다.
